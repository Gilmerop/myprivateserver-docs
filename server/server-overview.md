# 🖥️ Server Overview

This document outlines the general purpose and services of the `myprivateserver` project.

## 🔧 Server Role

- Centralized platform for virtual machines and containers.
- Hosts personal services for automation, file storage, network control, and development.

## 🧱 Core Software Stack

- **Proxmox VE** as hypervisor
- **Ubuntu Server** as main service VM
- Planned additions: Windows Server, Docker containers, and lightweight Linux distributions

## 🛰️ Network Integration

- Connected to LAN via TP-Link router
- Static private IP assigned
- Public access managed via OpenVPN
